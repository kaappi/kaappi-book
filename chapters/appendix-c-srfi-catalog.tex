\chapter{SRFI Catalog}
\index{SRFI!catalog}
\label{app:srfi}

All \srfitotal{} SRFIs supported by Kaappi, grouped by category. Import with \texttt{(import (srfi N))}. Chapter~\ref{ch:stdlib} covers the most commonly used SRFIs in depth. Each SRFI's full specification, rationale, and reference implementation are published at \url{https://srfi.schemers.org}.

\begin{note}[Built-in vs.\ Portable]
Of Kaappi's \srfitotal{} SRFIs, \srfibuiltin{} are compiled into the interpreter binary (marked with \textbf{*} below) for performance. Another \srfiportable{} are portable Scheme \texttt{.sld} files loaded on demand. The remaining four are imported differently: SRFI 261 is a naming convention with no library file at all, and SRFI 160, 211, and 226 ship only as sub-libraries (see the last section of this appendix).
\end{note}

sub-libraries. Asking for the bare form is an error.
